Docker

Command & Container Manifest

The commands for building images, shipping them through Docker Hub, and running the containers that carry them — in the order you'll actually reach for them.

Format · one page, five holds Docs · docs.docker.com Hub · hub.docker.com
01

Installation

Docker Desktop runs on Mac, Linux and Windows — docs.docker.com/desktop. Browse example projects at github.com/docker/awesome-compose, and the full reference at docs.docker.com.

02

Images

A lightweight, standalone package holding everything an application needs to run: code, runtime, system tools, libraries and settings.

CommandWhat it does
docker build -t <image_name> .Build an image from a Dockerfile
docker build -t <image_name> . --no-cacheBuild an image from a Dockerfile without the cache
docker imagesList local images
docker rmi <image_name>Delete an image
docker image pruneRemove all unused images
03

Docker Hub

Docker's registry for finding and sharing container images with your team — hub.docker.com.

CommandWhat it does
docker login -u <username>Log in to Docker
docker push <username>/<image_name>Publish an image to Docker Hub
docker search <image_name>Search Hub for an image
docker pull <image_name>Pull an image from Docker Hub
04

General

CommandWhat it does
docker -dStart the Docker daemon
docker --helpGet help with Docker — also works as --help on any subcommand
docker infoDisplay system-wide information
05

Containers

A runtime instance of an image. A container isolates software from its environment so it runs the same everywhere — dev, staging, wherever it lands.

CommandWhat it does
docker run --name <container_name> <image_name>Create and run a container from an image, with a custom name
docker run -p <host_port>:<container_port> <image_name>Publish a container's port(s) to the host
docker run -d <image_name>Run a container in the background
docker start|stop <container_name>Start or stop an existing container (name or container ID)
docker rm <container_name>Remove a stopped container
docker exec -it <container_name> shOpen a shell inside a running container
docker logs -f <container_name>Fetch and follow a container's logs
docker inspect <container_name>Inspect a running container (name or container ID)
docker psList currently running containers
docker ps --allList all containers, running and stopped
docker container statsView resource usage stats
